R package

VLabR

A lightweight R package for common data-cleaning and summary-table tasks in health data work: tidy column names, duplicate and uniqueness checks, one-row summaries, covariate balance, stable de-identified IDs and personal-name masking. Name masking can use Python and spaCy when available, with a pure-R fallback for locked-down work computers. Requires R 4.1.0 or later.

View VLabR on GitHub →

Install

install.packages("remotes")
remotes::install_github("LaboratoireV/VLabR", upgrade = "never")

library(VLabR)
vlab_load_vlabr_packages()
